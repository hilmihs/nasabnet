# NasabNet — web app

React + TypeScript + Tailwind CSS + Cytoscape.js (Vite). Data: `public/data/nasabnet.json`, built by `../scripts/build_dataset.py`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # static site in dist/
```

See the project README one level up for features, data sources, and the rebuild pipeline.
